# Power BI CoE — Certification Plan

An interactive, role-based guide to the Microsoft and GitHub certifications that the Power BI Center of Excellence recommends. It covers two tracks:

- **Data & Analytics:** DP-900 → PL-300 → DP-600 → DP-700
- **AI-assisted development:** AI-901 · GH-900 → GH-300 → GH-600 / GH-700

Source reference: [Microsoft Certifications Poster](assets/Certification-Poster.pdf) (Aug 2026).
